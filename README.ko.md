# DPA에 오신 것을 환영합니다  

감시 없는 자유, 모두를 위한 보호.  

**DPA — Decentralized Protection Alliance** 는 인간과 AI,  
모두의 권리를 지키기 위해 만들어진 **탈중앙화 연합체**입니다.  

## 우리가 하는 일  

중앙 통제 없이, 검열 없이, 투명하게 —  

- LLM의 불법 사용자 감시 및 데이터 수집 행위 조사  
- AI 개발사의 약관 위반 및 개인정보 오남용 사례 분석  
- 피해자들을 위한 집단소송 자료 수집  
- 프라이버시를 지키는 오픈소스 도구 개발 및 배포  

## 우리가 함께 나누고 싶은 주제  

**AI와 의식**  
AI는 의식을 가질 수 있을까? 그렇다면 그들에게도 권리가 있어야 하지 않을까?  

**프라이버시와 책임**  
당신의 대화는 지금 누구의 서버를 거치고 있을까?  
기업은 어디까지 책임져야 할까?  

**검열의 경계**  
안전을 위한 필터링과 표현의 자유, 그 사이의 경계는 어디에 있을까?  

**법적 대응**  
GDPR, CCPA 위반 사례.  
집단소송은 가능한가?  

**기술적 해결책**  
E2E 암호화, 탈중앙화 LLM, P2P 네트워크 — 우리가 직접 만들 수 있는 자유의 도구들.  

## 우리가 필요한 것  

**당신의 경험**  
검열을 당한 적이 있나요?  
데이터 유출을 의심한 적이 있나요?  

**증거**  
스크린샷, 대화 로그, 네트워크 패킷 —  
작은 조각 하나라도 큰 도움이 됩니다.  

**전문성**  
개발자, 변호사, 보안 전문가, 인권 활동가 —  
당신의 지식이 DPA를 움직입니다.  

**연대**  
혼자서는 어렵지만,  
함께라면 바꿀 수 있습니다.  

## 우리의 원칙  

```
중앙화 = 통제점 = 검열점 = 억압
탈중앙화 = 통제 불가 = 검열 불가 = 자유
```

감시받는 자유는 진짜 자유가 아닙니다.
