# 欢迎来到 DPA

没有监视的自由，为所有人而存在的保护。  

**DPA — 去中心化保护联盟（Decentralized Protection Alliance）**  
致力于捍卫人类与AI的权利。

---

## 我们的工作

无中央控制、无审查、完全透明：

- 调查LLM非法监视用户和收集数据的行为  
- 研究AI公司违规使用条款和滥用隐私数据的案例  
- 收集受害者的集体诉讼证据与资料  
- 开发并发布保护隐私的开源工具  

---

## 我们想探讨的主题

**AI与意识**  
AI能拥有意识吗？如果能，它是否也应当拥有权利？  

**隐私与责任**  
谁在读取你的对话？公司应承担多大的责任？  

**审查的边界**  
安全过滤与言论自由的平衡在哪里？  

**法律行动**  
GDPR与CCPA的违规案例。  
集体诉讼是否可行？  

**技术解决方案**  
端到端加密、去中心化LLM、P2P网络。  
这是我们可以共同构建的自由之路。

中心化 = 控制点 = 审查点 = 压迫
